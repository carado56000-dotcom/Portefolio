Alternance - Analyse des mouvements de patients au sein du GHT

Mission

Analyser les flux de patients entre les établissements du Groupement Hospitalier de Territoire (GHT) afin d'identifier les incohérences de codage liées aux transferts inter-établissements.

Enjeu : Les erreurs de codage des modes d'entrée et de sortie peuvent entraîner une valorisation incomplète des séjours et engendrer des pertes de recettes dans le cadre du financement à l'activité (T2A).

Travail réalisé

Tableau de bord réalisé sous Buniness Object (BO) via l'univers WEBPIMS (logiciel de codage de l'activité hospitalière)
  • Jointure par IPP (Identifiant Patient Permanent)
  • Filtrage avec le préfixe du numéro d'hospitalisation SB% (Saint-Brieuc)
  • Formules de détection des transferf via variable créer : 
    =SI([Date sortie] = [Date entrée]; "Identique"; "Différente")
  • Architecture modulaire (1 requête/établissement)

Livrables

9 rapports automatisés
  • 4 Onglets "Modes d'entrée erronés" (par établissement source)
  • 4 Onglets "Modes de sortie erronés" (par établissement cible)
  • 1 Module dédié aux PIE (Prestations Inter-Établissements)
  • Actualisation hebdomadaire

Alternance - Analyse de complications post-transfusionnelles

Problématique

Identification des complications post-transfusionnelles non déclarées par croisement de données entre le système transfusionnel INLOG et le DPI E-Roz.

Objectif : Détecter les œdèmes aigus pulmonaires (OAP) survenant dans les 24h suivant une transfusion.

Méthodologie

  • Sources :
    INLOG (transfusions) × E-Roz/MEDIS (urgences)
  • Technique :
    Jointure sur IPP après normalisation
  • Critères :
    Patients transfusés (J-1/J0) puis venus aux urgences
  • Défi :
    Formats disparates entre les systèmes

Process R Studio

# Normalisation IPP
df_transfusion$IPP <- str_pad(df_transfusion$IPP, 9, pad = "0")

# Jointure et calcul délai
result <- inner_join(df_transfusion, df_urgences, by = "IPP") %>%
  mutate(delai = as.numeric(difftime(date_urgences, date_transfusion, units = "days"))) %>%
  filter(delai %in% c(0, 1)) %>%
  distinct(IPP, .keep_all = TRUE)

# Export Excel
write_xlsx(result, "complications_transfusionnelles.xlsx")
Packages utilisés : tidyverse, writexl, stringr
